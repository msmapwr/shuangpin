# 双键 · 小鹤双拼练习

一个打开即可使用的小鹤双拼练习网站。练习声母、韵母、零声母、单字和高频词组，再通过错题复习巩固薄弱键位。

在线使用：[GitHub Pages](https://msmapwr.github.io/shuangpin/#tutorial)

## 本地运行

需要 Node.js 22.12+（或 20.19+）。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。切换为英文输入法，直接按键或点击屏幕键盘；手机点击输入区调出英文键盘。正确后自动进入下一题，错键停留，退格撤回当前题，Esc 暂停或继续。切换功能页面、打开弹窗或隐藏浏览器页面会暂停计时。

## 功能

- 面向已会盲打用户的八课入门教程，配有拆音示例、课后跟练、无提示验收和可调整进度。
- 声母、韵母、零声母、单字、高频词组分阶段练习。
- 四篇原创短文逐字跟练，全文高亮、标点自动跳过、暂停续练和文章记录。
- 引导 / 盲打模式、即时纠错、单题提示、交互键盘、暂停与重练。
- 可设置每轮 10 / 20 / 50 题、随机顺序、音效和每日目标。
- 按声母、韵母类型或词组主题选择练习范围，例如复合声母、前鼻韵母和后鼻韵母专项。
- 自定义词库支持批量添加、搜索、删除确认，以及独立词组练习。
- 轮次结算、七天练习统计、练习历史、错题本和针对性复习。
- 学习建议、分阶段表现与连续练习天数，均从实际完成记录计算。
- 当前标签页暂存未完成进度，刷新后可暂停恢复并继续，不重复累计完成记录。
- 键位速查、新手指南、响应式布局、键盘焦点、减少动态效果支持。
- 本地保存学习数据，支持 JSON 导出与合并导入；无账号、无学习数据上传、无虚构统计。

## 从全拼开始学小鹤

打开「入门教程」，按两键原理、声母、单韵母、复韵母、鼻韵母、零声母与 ü、词组、短文的顺序学习。课程假设你已经会盲打，直接讲每个音节怎么拆、按哪个键；每课都有例子和卡住时的补练办法。

「我读完了」只标记阅读进度。「先跟练」显示答案和下一个键，「无提示验收」会关闭这些提示。本站建议连续两轮无提示验收达到 95% 按键准确率后继续。验收中仍能显示提示，也能回看教程或速查等学习资料，该轮会标记为查阅过帮助，保留记录但不算无提示通过；准确率低于 90% 时建议回到跟练。这个标准用于安排本站练习，不保证学习天数或实际输入速度。

课程可以自由选择和回看，已验收标记不会因之后回练出错而删除。课后练习量可选轻量 10 题、常规 20 题或加练 30 题，下一轮生效，不改变自由练习设置；第八课始终练完 59 字短文。未完成轮次支持暂停与刷新恢复，包括课程范围、验收模式和是否用过提示。

课程位置、练习量、已读和已验收课次包含在 JSON 备份中。导入默认保留本机课程位置和练习量，合并两边的已读、已验收标记；勾选恢复设置时也恢复备份的课程位置与练习量。第一版 v1 备份缺少课程字段时会使用空课程进度。

## 文章跟练

练习台点击「文章跟练」，选择《晨间片刻》《林间散步》《工作日记》或《学习与坚持》。每篇 46～59 字，按全文顺序逐字输入完整双拼编码；标点与换行仅保留为阅读上下文，不需要输入。原文区高亮当前字，并在区内自动滚动。

文章始终练完整篇，不受每轮题数和随机设置影响。暂停、提示、退格、错题收集和刷新续练与基础课程一致；从目录继续当前短文会保留已输入的半个音节。切换短文或练习范围前会确认，未完成轮次不计入历史。完成后的历史及导出备份包含文章名称；错题同时标注原文和字序。

## 自定义词组

进入「我的词库」并点击「添加词组」，每行输入一个词组与拼音：

```text
你好 | ni hao
绿色 | lv se
小鹤双拼 | xiao he shuang pin
```

每个词组支持 2～8 个汉字，每字填写一个无声调标准拼音，音节用空格分隔，`ü` 可写为 `v` 或 `u:`。相同词组与拼音会去重，最多保存 200 个自定义词组。工具会检查支持的音节并生成编码；词组的实际读音由你指定，不会自动判断多音字。独立成音的 m、n、ng 等不在当前两键训练范围内。

添加后点击「开始练习」即可专练自定义词组。删除词组不会删除已经产生的历史或错题，也不会改变正在进行的轮次。

## 继续练习与学习建议

当前标签页使用 `sessionStorage`（`shuangjian-active-round-v1`）暂存正在练习的题目、范围、输入、提示状态和有效用时。刷新后保持暂停，点击「继续练习」或按 Esc 恢复；离开或暂停的时间不计入成绩。新开标签页独立练习，关闭标签页后不保证保留未完成轮次，临时进度不包含在学习数据导出中。

恢复前会校验题目、答案与计数。若数据不合法，会保留一份临时原始副本并准备新轮次；已有学习历史不受影响。若连副本也无法保存，保留原内容且不自动覆盖，需明确点击「重新开始」才放弃旧临时数据。已记入历史的轮次不会再次恢复；暂存失败时会显示提示，离开页面前仍会提醒。

「学习记录」和结算页提供下一步建议：优先复习当前错题，再按学习路线练习未开始的阶段；各阶段均有记录时，优先巩固最近准确率较低的一类。各阶段表现按最近最多三轮的正确按键数 / 尝试按键数加权计算，不将引导练习成绩称为盲打掌握程度。连续练习天数按当前浏览器的日历日期统计，截至今天或昨天，重复轮次不会重复计算天数。

错题复习一轮内每题只出现一次，不足设置题数时按实际错题数结算；答题过程中仍需纠正错按后才能进入下一题。

## 数据与统计

数据存于当前浏览器的 `localStorage`（`shuangjian-progress-v1`），不同设备不会自动同步，清除浏览器数据会丢失记录。学习记录页面可导出 JSON 快照。历史保留最近 500 轮；未完成轮次不记入历史，错题即时保存。记录损坏时保留原数据并提示，不自动覆盖。

在「学习记录 → 导入备份」选择 JSON 文件（最大 2 MB），核对摘要后确认合并。兼容第一版导出的备份；历史按 ID 去重并保留最近 500 轮，自定义词库取并集，错题次数取较大值而不相加。重复导入同一备份不会重复累计历史；旧备份可能带回已掌握的错题。默认保留本机设置，也可以勾选恢复备份设置。

导入会校验记录、音节与答案；冲突记录或词库超限会取消导入。保存失败时不会替换原记录。若原记录已无法读取，确认恢复时会先将原始内容保存至本机独立的 `shuangjian-progress-v1-recovery-<时间戳>` 键，再写入恢复结果。该恢复副本也会随浏览器数据清理而删除。

准确率 = 正确按键次数 / 总尝试按键次数。有效按键速度 = 已完成题目的编码长度 / 有效练习分钟数，**不等同于汉字/分钟**。暂停时间不计入。复习中一次无错完成的题目会移出错题本。

## 验证与构建

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

浏览器测试使用 Playwright 自带 Chromium；可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装的 Chromium。`npm run build` 包含 TypeScript 检查并生成 `dist/`；可部署至任意静态托管平台。Sites 的身份和静态产物目录见 `.openai/hosting.json`。

## 技术与规则

Vite、TypeScript、GSAP、Lucide。GSAP 仅用于短暂入场与纠错反馈，尊重 `prefers-reduced-motion`。字体使用 Noto Sans SC，加载失败回退系统中文字体。

练习使用标准小鹤双拼音码，按音节顺序完整输入，不包含小鹤音形辅助码或词组简码。规则依据 [小鹤官网](https://flypy.cc/) 与 [Rime 官方小鹤方案](https://github.com/rime/rime-double-pinyin/blob/master/double_pinyin_flypy.schema.yaml)。词库采用人工标注拼音以消除多音字歧义。

开发计划、设计和验收标准见 [docs/PLAN.md](docs/PLAN.md)。

## GitHub Pages 发布

仓库已启用 GitHub Actions 作为 Pages 来源。推送到默认分支后，Verify 先执行格式、单元测试、构建和浏览器测试，全部通过后才由 `deploy-pages` 发布 `dist/`。其他分支与 PR 只执行验证。也可以在 Actions 页面手动运行 Verify，发布仍限制在默认分支。

Vite 使用相对资源路径，支持 `https://msmapwr.github.io/shuangpin/`，并继续兼容原 Sites 根地址。页面使用 hash 路由，教程直达地址是 `/#tutorial`。如需在自己的仓库复用，在 Settings → Pages 中将 Source 设为 GitHub Actions，然后推送到默认分支。

GitHub Pages 与 Sites 属于两个不同的网站来源，本机学习记录不会自动共享。要继续原来的进度，先在原站点「学习记录」中导出 JSON，再到 Pages 的「学习记录」导入。

工作流使用 [GitHub Pages 官方自定义工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) 中的部署操作，不需要额外的个人访问令牌或仓库 Secret。
