# 文章跟练迭代计划

目标：在现有声韵母、单字与词组练习之后，提供保留上下文的逐字短文练习。

1. 四篇原创短文，显式标注读音；按原文顺序完整出题，标点自动跳过。
2. 练习台增加文章入口与目录子页，保留五项主导航；全文显示已完成和当前字，兼容移动端和减少动态效果。
3. 沿用即时纠错、暂停、提示、错题复习及刷新恢复；备份校验识别文章题目和文章记录，兼容旧版 v1 数据。
4. 验证完整文章超过普通题数设置时仍可练完，刷新保持原顺序，切换取消保护当前轮次；完成后检查构建、测试、Diff、CI 与私有站点发布。

范围：不新增账户、数据库或依赖，不改变基础课程及原有统计口径。文章每字为一道题，速度仍按有效按键计算。
