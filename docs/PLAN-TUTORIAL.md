# 入门教程与 GitHub Pages 计划

读者已经能正常盲打，熟悉全拼。教程直接讲小鹤双拼的拆音节、编码和练习方法，不重新教指法。

课程顺序：两键原理 → 声母 → 单韵母 → 复韵母 → 鼻韵母 → 零声母与 ü → 连续词组 → 短文与日常使用。每课提供具体例子、容易混淆的地方和课后练习。

课程练习分带提示的跟练和关闭提示的验收。建议连续两轮无提示验收达到 95% 按键准确率后继续；使用提示的轮次保留记录但不算验收通过。这是本站的练习建议，不承诺学习天数或速度。读过和通过分别记录，允许自由选课、回练，并可选择每轮 10 / 20 / 30 题。短文练完整篇。

保留现有自由练习与 v1 数据格式，增加可选课程字段。备份合并保留已读与已验收课程；恢复轮次时校验课程范围、模式和提示状态。

沿用雾白、墨蓝和靛蓝配色，教程正文使用系统中文字体，16px 起、宽行距。桌面左侧课程目录、右侧阅读与课后练习；手机折叠目录。用拆音示例和分组键位表辅助理解，不将每段正文拆成卡片。过渡复用现有 GSAP，并尊重减少动态效果。

GitHub Pages 使用官方 Actions 工作流，测试和构建通过后部署。构建支持仓库子路径；现有 Sites 根路径部署继续可用。Pages 与 Sites 是不同来源，本地记录需通过 JSON 导入导出转移。

校验来源：小鹤官网、Rime 官方小鹤方案、GitHub Pages 官方自定义工作流文档。中文说明按 humanizer 规则复核，删除口号、重复收尾和没有依据的学习效果承诺。
