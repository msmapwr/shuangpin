# 双键开发计划

## 目标与边界

为初学者提供可直接使用的小鹤双拼练习台。先建立声母和韵母的键位记忆，再练习零声母、单字和词组。使用浏览器本地存储，无需账号，不引入服务端或付费功能。不包含小鹤音形辅助码，也不将词组压缩为音形四码。

## 设计方案

- 色彩：雾白 #F6F7FB、纸白 #FFFFFF、墨蓝 #252A43、靛蓝 #5664DC、薄荷绿 #26836A、浅紫 #EEF0FF。
- 字体：中文使用系统苹方 / 微软雅黑；英文与数字使用系统 sans-serif。字母键帽使用等宽字体以模拟键盘。
- 布局：左侧学习导航，中间拼音练习与交互键盘，右侧学习路径和每日目标；小屏折叠为横向导航与单列。
- 特色：拼音、键位与手指记忆直接关联。首屏就是可操作的练习，不使用营销式 hero。靛蓝只强调当前任务与正确键位；状态同时使用文字表达。

```text
品牌 / 学习导航 | 当前练习、模式、设置
              | 轮次统计                  | 学习路径
              | 大号题目与输入键帽         | 今日目标
              | 小鹤交互键盘              | 学习提示
              | 后续学习模块
```

## 实施单元

1. 规则与内容：编码函数、声韵母表、零声母、人工标注拼音的词库。
2. 练习闭环：出题、逐键校验、错误停留、提示、暂停、轮次结算与重练。
3. 学习支持：键位参考、入门说明、错题复习、本地历史与设置、导出。
4. 验证交付：编码边界验证、浏览器关键流程、375/768/1440 布局、reduced-motion、生产构建、Diff 审查与发布。

## 验收标准

- zh/ch/sh、所有韵母映射、零声母 a/o/e 与 ai/ang/eng、ü、j/q/x/y + u 编码正确。
- 错键不推进题目；退格可撤回当前题输入；暂停与页面隐藏不计时；完成仅保存一次。
- 首次使用无伪造统计；练习记录刷新保留；存储不可用时明确提示。
- 所有按钮提供真实操作；可使用物理键盘、屏幕键盘和手机英文键盘。
- 导航、帮助与设置支持键盘访问；动画尊重减少动态效果。

## 规则来源

- 小鹤官网：https://flypy.cc/
- Rime 官方小鹤方案：https://github.com/rime/rime-double-pinyin/blob/master/double_pinyin_flypy.schema.yaml
- 编码兼容标准小鹤双拼，练习使用完整音节编码；非输入法候选引擎。
